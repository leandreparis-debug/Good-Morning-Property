| Point                                                | Status                   | How it is enforced / checked                                                                                                                                                                                                                                                                                              |
| ---------------------------------------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| RLS on every table, default deny                     | ✅                       | pgTAP `04_schema_security` (RLS on every `public` table, no `anon` privilege, immutable columns, pinned `search_path`), plus per-rule tests `02`–`07`.                                                                                                                                                                    |

Never set it on Vercel.                                                                                                                                                                |
| No email ever sent                                   | ✅                       | No SMTP config; sign-in through `generateLink` + `verifyOtp` server-side. e2e `zz-no-mail.spec.ts` checks Mailpit is empty after the whole suite.                                                                                                                                                                         |
| Sign-ups disabled                                    | ✅ local / ⚠️ production | `supabase/config.toml` (`enable_signup = false`); **to do by hand on the hosted project** (`docs/deploy.md`, step 1).                                                                                                                                                                                                     |

## Accepted limits

- Whoever holds a personal link acts on behalf of the member (see `docs/auth.md`).
- After a deactivation, an already-issued access token stays technically valid until it expires
  (≤ 1 h), but the middleware and the RLS refuse everything at once.
- The rate limit is per server instance (serverless), not global.
